# Mutual NDA template

- **Use when** both parties share confidential information, e.g. while evaluating a deal.
- **Don't use when** only one side discloses: use a [unilateral NDA](../unilateral-nda-template/).

**Not sure which?**

- Non-US governing law → oneNDA or Bonterms.
- US deal, everything in one file → Common Paper.

| | [Bonterms 1.0](bonterms-mutual-nda-v1.0.md) | [Common Paper 1.0](common-paper-mutual-nda-v1.0.md) | [oneNDA 2.1](onenda-v2.1.md) |
|---|---|---|---|
| Structure | Standard terms; deal terms on a separate [Cover Page](https://bonterms.com/download-center/mutual-nda) | Cover Page + Standard Terms | Parties, Variables and Terms |
| Governing law | Chosen on the Cover Page | A US state | Any, with litigation or arbitration |
| Length | ~1,100 words | ~1,300 words | ~950 words |
