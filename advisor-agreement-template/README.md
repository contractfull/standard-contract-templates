# Advisor agreement template

The [General Legal Advisor Agreement](general-legal-advisor-agreement.md): a startup advisor paid in stock options, with IP assignment and confidentiality.

**Use when** a startup brings on an advisor for equity.
**Don't use when** the advisor is paid cash for defined work: use a [services agreement](../professional-services-agreement-template/).

| | General Legal Advisor Agreement |
|---|---|
| Covers | Services, option grant, IP, confidentiality, non-solicitation, termination |
| Governing law | Delaware |
| License | CC0 1.0 |
