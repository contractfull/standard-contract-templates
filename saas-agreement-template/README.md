# SaaS agreement template

- **Use when** you sell or buy a hosted software subscription.
- **Don't use when** the customer installs the software ([software license](../software-license-agreement-template/)) or the deal is mostly services ([PSA](../professional-services-agreement-template/)).

**Not sure which?**

- You'll attach an SLA or DPA from the same family → Bonterms or Common Paper.
- Everything in one document → oneSaaS.

| | [Bonterms Cloud Terms 1.0](bonterms-cloud-terms-v1.0.md) | [Common Paper CSA 3.0](common-paper-cloud-service-agreement-v3.0.md) | [oneSaaS 1.0](onesaas-v1.0.md) |
|---|---|---|---|
| Structure | Standard terms; deal terms on a separate [Cover Page](https://bonterms.com/download-center/cloud-terms) | Order Form + Key Terms + Standard Terms | Cover Page + Standard Terms + addenda |
| Add-ons | [SLA](../sla-template/bonterms-service-level-agreement-v1.0.md), [DPA](../data-processing-agreement-template/bonterms-data-protection-addendum-v1.0.md) | [SLA](../sla-template/common-paper-service-level-agreement-v2.0.md), [AI Addendum](../ai-addendum/common-paper-ai-addendum-v1.0.md) | SLA, trials, add-on services (built in) |
| Governing law | Chosen on the Cover Page | Chosen in the Key Terms | Chosen in the Key Terms |
