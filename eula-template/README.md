# EULA template (app marketplaces)

The [Bonterms Standard End User Agreement](bonterms-standard-end-user-agreement-v1.0.md): end user terms between a software provider and a customer buying through an app marketplace.

- **Use when** you list a cloud service or installed software on a marketplace that offers it.
- **Don't use when** you sell directly: use a [SaaS agreement](../saas-agreement-template/) or [software license](../software-license-agreement-template/).

| | Bonterms Standard End User Agreement 1.0 |
|---|---|
| Parties | Provider and Customer (the marketplace is not a party) |
| Customising | Provider-Specific Terms in the listing |
| Governing law | California, unless the listing says otherwise |
| License | CC BY-ND 4.0 |
