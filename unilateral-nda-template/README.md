# Unilateral NDA template (one-way NDA)

- **Use when** only one party discloses, e.g. to a contractor, candidate or investor.
- **Don't use when** both sides share information: use a [mutual NDA](../mutual-nda-template/).

**Not sure which?**

- Deal terms on a cover page → Common Paper.
- Full standalone agreement → General Legal.

| | [Common Paper](common-paper-one-way-nda.md) | [General Legal](general-legal-one-way-nda.md) |
|---|---|---|
| Structure | Cover Page + NDA Terms | Single agreement |
| Governing law | A US state | Delaware |
| Length | ~1,200 words | ~1,800 words |
