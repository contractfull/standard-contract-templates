# EU Data Act model terms

The European Commission's model contracts under Article 41 of the Data Act ([Recommendation 2026/2394](https://eur-lex.europa.eu/eli/reco/2026/2394/oj)).

- **Use when** you share data from connected products, or switch cloud providers.
- **Don't use when** the issue is personal data: use a [DPA](../data-processing-agreement-template/).

| File | Between |
|---|---|
| [Data holder and user](eu-data-act-mct-data-holder-to-user.md) | The product maker (data holder) and the user of a connected product |
| [User and data recipient](eu-data-act-mct-user-to-data-recipient.md) | The user and a third party it wants the data sent to |
| [Data holder and data recipient](eu-data-act-mct-data-holder-to-data-recipient.md) | The data holder and that third party |
| [Voluntary data sharing](eu-data-act-mct-voluntary-data-sharing.md) | Any parties sharing data outside the mandatory regime |
| [Cloud switching clauses](eu-data-act-cloud-sccs.md) | A cloud customer and its provider |
