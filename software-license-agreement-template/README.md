# Software license agreement template

- **Use when** the customer installs and runs the software (on-premises, self-hosted).
- **Don't use when** you host it and sell access: use a [SaaS agreement](../saas-agreement-template/).

**Not sure which?** Use the family you already use for SaaS and services.

| | [Common Paper 1.1](common-paper-software-license-agreement-v1.1.md) | [Bonterms 1.0](bonterms-software-license-terms-v1.0.md) |
|---|---|---|
| Structure | Standard Terms; [Order Form and Key Terms](https://commonpaper.com/standards/software-license-agreement/1.1/) online | Standard terms; [Cover Page](https://bonterms.com/download-center/software-license-terms) online |
| Governing law | Chosen in the Key Terms | Chosen on the Cover Page |
| Length | ~5,200 words | ~4,400 words |
| License | CC BY 4.0 | CC BY 4.0 |
